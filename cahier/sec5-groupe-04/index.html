Active ton cahier en ligne.

Cinq étapes, une dizaine de minutes. Le code de ton groupe est sur cette page.

Il te faut
  1. 1

    Ouvre la page de connexion

    iplusinteractif.com→
  2. 2

    Crée ton compte

    Clique sur Créer mon compte, puis écris ton courriel de l'école. Jamais ton courriel personnel.

  3. 3

    Choisis un mot de passe

    • 8 caractères ou plus
    • une majuscule
    • une minuscule
    • un chiffre
    • un symbole (! ? # $)

    ⚠ ImportantÉcris ton mot de passe au bas de la 1re page de ton cahier. Si tu l'oublies, tu auras de la difficulté à revenir dans ton cahier en ligne les prochaines fois.

  4. 4

    Entre ton code d'activation

    Ouvre ton cahier à la première page. Enlève le collant : ton code est en dessous. Recopie-le dans le formulaire.

  5. 5

    Rejoins ton groupe

    Dans ton cahier en ligne, entre le code de ton groupe :

    439232
